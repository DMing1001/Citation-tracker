收稿范围

Aims & Scope

Geomorphology 覆盖各类地貌过程与形态演化：坡面、河流、海岸、冰缘、风成、构造地貌等，强调过程—形态—演化机制。

  • 坡面过程：侵蚀、滑坡、泥石流、风化
  • 河流地貌：河型、河床演变、流域地貌
  • 海岸与海底地貌、风暴与沉积
  • 风成地貌、干旱区过程
  • 冰川/冰缘地貌与高寒过程
  • 构造—气候—地貌耦合
  • 地貌定年、监测与数值模拟

⚠️ 不接受的稿件类型

  • 与地貌过程无关的纯土壤化学或纯污染研究
  • 无过程解释的景观描述与制图
  • 工程设计说明书而缺地貌科学问题
✅

适合什么稿

什么样的稿子适合投这里

适合有地貌过程机理、有多时间/多空间尺度证据的研究。关键在「形态如何形成、如何演化」。

  • 过程驱动清楚：水力、重力、风力、冻融等
  • 证据链完整：观测/年代/实验/模型至少一项扎实
  • 时空尺度交代清楚，避免把相关当因果
  • 对地貌演化理论或区域地貌有贡献

⚠️ 常见拒稿 / 不匹配点

  • 纯遥感分类、无地貌过程解释
  • 小范围描述性地貌志
  • 与 CATENA 偏土壤过程相比，本刊更偏形态与地貌演化；纯土壤理化可考虑他刊
  • 缺定年或缺过程量测却下强结论

以上为投稿匹配提示，综合自期刊 Aims & Scope 与编辑惯例，非官方拒稿清单。以最新 Guide for Authors 为准。

审稿流程时间线

  1. 提交 → 编辑初审 / Desk Review
  2. 送审 → 邀请审稿人
  3. 审稿 → 2–4 月
  4. 决定 → Major / Minor / Accept / Reject
  5. 修改 → 逐条回复审稿意见
  6. 最终决定 → 编辑确认

申诉与转投

如对决定有异议，按期刊政策提交申诉；被拒后可能收到转投建议，具体以出版社流程为准。

投稿流程

投稿步骤

  1. 登录 Editorial Manager
  2. 选择文章类型
  3. 填写标题、摘要、关键词
  4. 添加作者与单位
  5. 上传稿件与 Cover Letter
  6. 填写 Funding / Data Availability 等声明
  7. 确认提交

Cover Letter 要点

  • 研究问题与主要发现（2–3 句）
  • 创新点与适合本刊的理由
  • 未一稿多投声明
  • 通讯作者联系方式

投稿后注意事项

  • 超过约 6–8 周无进展可礼貌询问编辑部
  • 按决定信要求的期限提交修改稿
  • 校样阶段通常仅允许改正排版错误
📄

稿件准备

文章结构

  • Title — 简洁信息型标题，避免夸张
  • Abstract — 以 Guide for Authors 的摘要要求为准（常见约 150–250 词）
  • Keywords — 3–6 个
  • Introduction / Methods / Results / Discussion
  • Declarations — Funding / COI / CRediT / Data

语言与作者

  • English
  • 建议绑定 ORCID，通讯作者通常需要
  • 单盲；若双盲则作者信息不进正文
📐

格式要求

文件与排版

  • 源文件：Word 或 LaTeX（以本刊 Guide 为准）
  • 页边距/行距：若无强制要求可从简，但需清晰可审
  • 图表：矢量优先，位图建议 ≥300 dpi；复杂图建议提供可编辑源
  • 补充材料：与正文交叉引用，命名清晰

字数与页数

  • Research Article 建议 8000–12000 词量级（以本刊为准）
  • 充分覆盖关键文献，避免堆砌

投稿清单

提交前检查以下事项

  • 稿件符合期刊 Aims & Scope
  • 文章类型选择正确
  • 标题与摘要符合本刊要求
  • 关键词数量达标
  • 作者信息完整，含 ORCID（如需）
  • CRediT / 作者贡献已填写
  • 通讯作者已标注
  • 利益冲突声明已准备
  • 基金信息完整
  • 数据可用性声明已提供
  • 图表格式与分辨率达标
  • 参考文献格式正确
  • 所有图表在正文中已引用
  • 语言经过润色
  • Cover Letter 已准备
  • 未同时投其他期刊

伦理与政策
