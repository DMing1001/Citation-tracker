收稿范围

Aims & Scope

Geomorphology 发表地貌过程与地貌演化的原创研究，覆盖侵蚀—搬运—沉积全链条，以及构造、气候与人类活动对地貌的驱动。

  • 坡面过程与土壤侵蚀地貌学
  • 河流地貌：河型、阶地、河岸演变
  • 海岸与海底地貌过程
  • 冰川与冰缘地貌
  • 风沙与干旱区地貌
  • 构造地貌与地貌计量学
  • 人类世地貌与恢复地貌学
  • 地貌测年、监测与数值模拟

⚠️ 不接受的稿件类型

  • 无地貌过程的纯土壤化学或污染研究
  • 纯水文预报、无地貌响应
  • 景观美图描述、缺定量过程
  • 与 CATENA 相比本刊更强调地貌演化与多过程耦合
✅

适合什么稿

什么样的稿子适合投这里

适合「过程—形态—演化」链条完整的研究。有侵蚀产沙、河道冲淤、坡面演化的水利/水保工作可认真考虑。

  • 侵蚀与沉积过程的定量与机制
  • 河流/河口冲淤与地貌调整
  • 多源数据（测年、遥感、地形）支撑的地貌演化
  • 人类活动（水库、堤防、采矿）的地貌效应
  • 与 CATENA/IJSR 成套，偏地貌科学叙事

⚠️ 常见拒稿 / 不匹配点

  • 措施效益评估若无地貌过程解释会偏管理刊
  • 小范围制图无过程假说
  • 纯工程布置、无地貌调整分析
  • 跨尺度结论缺乏地貌学框架

以上为投稿匹配提示，综合自期刊 Aims & Scope 与编辑惯例，非官方拒稿清单。以最新 Guide for Authors 为准。

投稿流程

投稿步骤

  1. 登录 Editorial Manager (Elsevier)
  2. 选择文章类型
  3. 填写标题、摘要、关键词
  4. 添加作者与单位
  5. 上传稿件与 Cover Letter
  6. 填写 Funding / Data Availability 等声明
  7. 确认提交

Cover Letter 要点

  • 研究问题与主要发现（2–3 句）
  • 创新点与适合本刊的理由
  • 未一稿多投声明
  • 通讯作者联系方式
