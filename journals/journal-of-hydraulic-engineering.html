收稿范围

Aims & Scope

Journal of Hydraulic Engineering（ASCE）发表水力学理论、数值与实验研究，服务土木/水利/环境工程中的流动问题。

  • 明渠水力学、堰闸、消能与非恒定流
  • 紊流、泥沙起动与输移、河床演变基础
  • 计算水力学：格式、验证与确认（V&V）
  • 水工建筑物水力学、泵站与管道
  • 环境水力学：混合、扩散、浮射流
  • 实验方法与量测技术

⚠️ 不接受的稿件类型

  • 纯水文预报、无流动机理
  • 商业软件常规算例、无方法或机理新意
  • 与水力学无关的结构/岩土/纯管理稿件
✅

适合什么稿

什么样的稿子适合投这里

适合工程背景明确、流动机理或方法有贡献的稿件。要交代清楚边界条件、验证方式与工程含义。

  • 问题定义清楚：几何、边界、流动类型、无量纲参数
  • 有验证：实验数据、解析解、基准算例或网格收敛
  • 方法/机理新意可陈述，而不是「跑了个模型」
  • 结论对工程设计或流动理解有直接帮助

⚠️ 常见拒稿 / 不匹配点

  • 缺乏验证的 CFD 展示
  • 纯经验拟合、无机理或适用范围讨论
  • 与 JHE 范围不符的纯水资源规划
  • 数学/物理表述不严谨

以上为投稿匹配提示，综合自期刊 Aims & Scope 与编辑惯例，非官方拒稿清单。以最新 Guide for Authors 为准。

单盲审稿。首轮通常 2–4 月，以编辑部实际进度为准。

审稿流程时间线

  1. 提交 → 编辑初审 / Desk Review
  2. 送审 → 邀请审稿人
  3. 审稿 → 2–4 月
  4. 决定 → Major / Minor / Accept / Reject
  5. 修改 → 逐条回复审稿意见
  6. 最终决定 → 编辑确认

申诉与转投

如对决定有异议，按期刊政策提交申诉；被拒后可能收到转投建议，具体以出版社流程为准。

投稿流程

投稿步骤

  1. 登录 Editorial Manager (ASCE)
  2. 选择文章类型
  3. 填写标题、摘要、关键词
  4. 添加作者与单位
  5. 上传稿件与 Cover Letter
  6. 填写 Funding / Data Availability 等声明
  7. 确认提交

Cover Letter 要点

  • 研究问题与主要发现（2–3 句）
  • 创新点与适合本刊的理由
  • 未一稿多投声明
  • 通讯作者联系方式

投稿后注意事项

  • 超过约 6–8 周无进展可礼貌询问编辑部
  • 按决定信要求的期限提交修改稿
  • 校样阶段通常仅允许改正排版错误
📄

稿件准备

文章结构

  • Title — 简洁信息型标题，避免夸张
  • Abstract — 以 Guide for Authors 的摘要要求为准（常见约 150–250 词）
  • Keywords — 3–6 个
  • Introduction / Methods / Results / Discussion
  • Declarations — Funding / COI / CRediT / Data

语言与作者

  • English
  • 建议绑定 ORCID，通讯作者通常需要
  • 单盲；若双盲则作者信息不进正文
📐

格式要求

文件与排版

  • 源文件：Word 或 LaTeX（以本刊 Guide 为准）
  • 页边距/行距：若无强制要求可从简，但需清晰可审
  • 图表：矢量优先，位图建议 ≥300 dpi；复杂图建议提供可编辑源
  • 补充材料：与正文交叉引用，命名清晰

字数与页数

  • Research Article 建议 8000–12000 词量级（以本刊为准）
  • 充分覆盖关键文献，避免堆砌

投稿清单

提交前检查以下事项

  • 稿件符合期刊 Aims & Scope
  • 文章类型选择正确
  • 标题与摘要符合本刊要求
  • 关键词数量达标
  • 作者信息完整，含 ORCID（如需）
  • CRediT / 作者贡献已填写
  • 通讯作者已标注
  • 利益冲突声明已准备
  • 基金信息完整
  • 数据可用性声明已提供
  • 图表格式与分辨率达标
  • 参考文献格式正确
  • 所有图表在正文中已引用
  • 语言经过润色
  • Cover Letter 已准备
  • 未同时投其他期刊

伦理与政策

利益冲突 / 作者贡献 / 数据政策

  • 无利益冲突时按期刊模板声明 Competing Interests
  • AI 不能列为作者；若实质性辅助写作，须按政策声明
  • 鼓励数据/代码可用；涉及敏感数据需说明获取途径
