常见错误

计算不收敛？先查这几项

整理自建模与教学中的高频问题。遇到 Error / Warning 时，可按顺序对照排查。更细的操作步骤见文档中心。

本页不在站内导航公开入口，仅供定向分享；搜索引擎已标记 noindex。

1. 非恒定流不收敛 / 结果震荡

常见表现：Compute 后大量 Error，水位过程线锯齿状，或中途崩溃。

  • 检查 时间步长 是否满足 CFL：二维尤其敏感，先用较大网格 + 较大步长试通，再加密。
  • θ 加权因子建议 0.6–1.0；发散时可先调到 1.0 再逐步回退。
  • 确认初始条件合理：推荐从恒定流结果导入，避免“干河床突然来大流量”。
  • 边界过程线时间范围是否覆盖整个计算时段；插值是否异常。

相关：一维非恒定流教程 · 二维教程

2. 断面间距与收缩/扩张系数

常见表现：恒定流也有 Error/Warning，或水面线局部跳变。

  • 断面间距过密或过疏都可能不稳；桥、堰、汇口附近应加密，顺直段可放宽。
  • 收缩 / 扩张系数常见起点：收缩约 0.1、扩张约 0.3，再按河段特性调整。
  • 检查断面是否交叉、高程是否倒挂、滩槽糙率是否设反。
  • 无效区域（Ineffective Flow Areas）在漫滩和死水区要设，否则过流能力虚高。

相关：一维用户手册

3. 二维网格质量差导致算不动

  • 基础网格尺寸建议不小于 DEM 分辨率的约 2–3 倍，再用 Breaklines 沿河槽加密。
  • 堤防、道路必须用 Breaklines，避免网格单元“跨过”堤顶。
  • 避免过小或细长畸形单元；先粗网格验证模型，再逐步加密。

相关：二维网格教程

4. 单位与数据源对不上

  • 流量、水位、糙率、粒径的单位在输入表与解析逻辑中必须一致（本站工具页尤其注意）。
  • 从 CAD / Excel 导入断面时，先核对坐标系与高程基准（北京54 / 西安80 / WGS84 等）。
  • DEM 与断面高程基准不一致时，会出现“算得动但淹没范围不合理”。

相关：实战经验：坐标系与投影

5. 桥梁 / 壅水结果不合理

  • 核对桥墩阻水面积、梁底高程、冲刷系数 P 的定义是否与规范一致。
  • 能量法 / 动量法 / General 法适用场景不同；急变流、桥渡附近优先关注动量类方法。
  • 壅水高度异常偏大时，先检查过水面积与行近流速是否被低估。

相关：站内 桥梁壅水计算工具

6. 公式以 PDF 为准却算不对

  • 规范 PDF 排版会丢失上下标、分式与括号层级，必须与 Excel 计算表或原始文献交叉验证。
  • 重点核对：指数数值（如 5/3 不是 3/5）、指数作用的底数项、分子分母结构。
  • 个别规范条文可能存在笔误，以工程界通行算法与计算表为准并在说明中注明。
